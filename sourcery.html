Why the grid-only restriction existed, and how it is kept. Touch scrolling, as you recalled. The rule moved from JavaScript into CSS: touch-action: pinch-zoom on the pip cells means a finger there drags a box and a finger anywhere else scrolls, exactly as before. With a mouse there is no scroll gesture, so a box may start anywhere that is not a button, select, link, or the help modal. One pointer-event code path replaces the mouse and touch pairs. If the browser takes a touch for scrolling after a few moves, the gesture is cancelled and the previous selection is restored, which a new Chromium touch qual checks.

  6. Off-grid pips encode into the URL by nearest cell edge rather than nearest cell center.
